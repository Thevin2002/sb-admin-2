# Sb Admin 2

Personal project by **Thevin2002**, built on top of an open-source project.

## How to run

Open `index.html` in a browser. All libraries are included in `vendor/`.

To change the styles and rebuild:

```bash
npm install
npx gulp build   # compile Sass and minify
npm start        # watch + live reload
```

Tested: `npm install` and the Gulp build succeed on Node 24 (Sass compiler updated from node-sass to Dart Sass).
